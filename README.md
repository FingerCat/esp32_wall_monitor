# esp32_wall_monitor

This is a simple python and html app 

to see WiFi signals and motions with an ESP32 with a 3D WebUi.

1. Create a folder named esp32_wall_monitor and

create a file named app.py

2. Copy the python script into it.

3. Create another folder into esp32_wall_monitor

who you will name templates.

4. Then ceeate an html file into "templates"

who you will name index.html and then copy

the code into it, save it all.

5. Start by typing python3 app.py

6. Connect to http://localhost:5000

7. Enjoy ;)
