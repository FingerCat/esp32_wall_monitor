# esp32_wall_monitor

after creating app.py into the esp32_wall_monitor
you'll have to create a folder named "templates" 
inside esp32_wall_monitor 
then you will create a file inside templates named
index.html
and then copy the index.html code inside it.
then you can save it all and launch the script
by typing python3 app.py and access 
http//:localhost:5000 to see in real time 3D
signals and motions around you by using wifi and ESP32.
